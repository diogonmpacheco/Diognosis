# Good First Data Issues

These are safe places for contributors to help Diognosis grow without needing to change scoring logic.

Every contribution should stay in the candidate or live pending-review lane until reviewed. Source-linked does not mean professionally reviewed.

## Starter Areas

| Area | Good first task | Where it lands |
|---|---|---|
| DailyMed label metadata | Add or refresh public label identifiers for a high-priority drug | Label context candidate |
| CPIC/ClinPGx coverage | Check whether a gene-drug pair has a mapped Diognosis drug and selectable gene | PGx candidate |
| Parent-metabolite maps | Confirm parent, active metabolite, toxic metabolite, enzyme, and clearance pathway | Parent-metabolite candidate |
| PK/timing | Add half-life or washout metadata with source identifiers | PK/timing candidate |
| Interaction evidence | Link an existing warning to PMID/DOI/label/guideline identifiers | Evidence candidate |

## High-Value First Pass List

- Tacrolimus, Fluconazole, CYP3A4/CYP3A5, and P-gp/ABCB1
- Clopidogrel and CYP2C19
- Codeine and CYP2D6
- Tamoxifen and CYP2D6
- Capecitabine and DPYD
- Irinotecan and UGT1A1
- Azathioprine or mercaptopurine with TPMT/NUDT15
- Warfarin with CYP2C9, VKORC1, and CYP4F2
- G6PD oxidant-risk medications
- Succinylcholine with BCHE/RYR1 context

## Contribution Rules

- Use public identifiers and metadata rather than copied full text.
- Do not paste full abstracts, tables, figures, or copyrighted label bodies.
- Keep summaries in Diognosis’s own words.
- Mark records as pending professional review.
- Use “review prompt” and “source-linked pending review,” not clinical certainty language.
